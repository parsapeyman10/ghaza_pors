# دفترچهٔ شماره‌های داخلی — اپ پرتابل (GhazaPors Directory)

یک برنامهٔ **پرتابل و بدون نصب** برای ثبت «نام و نام خانوادگی» و «شمارهٔ تلفن داخلی» با
**جست‌وجوی هوشمند + پیشنهاد خودکار اسم‌ها** روی **دیتابیس واقعی SQLite**.

- ✅ صفر نصب: فایل `GhazaPors.exe` را دابل‌کلیک می‌کنید، برنامه در مرورگر باز می‌شود.
- ✅ دیتابیس: یک فایل `data/dahili.sqlite` **کنار خود برنامه** (قابل کپی روی فلش، قابل بکاپ‌گیری).
- ✅ چند کاربره روی شبکهٔ داخلی: یک سیستم اجرا می‌کند، بقیه با مرورگر وصل می‌شوند.
- ✅ ثبت، ویرایش، حذف، جست‌وجو، خروجی اکسل (CSV)، بکاپ و بازیابی.
- ✅ کاملاً فارسی و راست‌به‌چپ، آفلاین، بدون اینترنت و بدون هیچ نصب اضافه.

---

## ۱) اجرا روی ویندوز

> ✅ فایل آماده در **Releases** همین مخزن: `GhazaPors-win-x64.zip` (ویرایش v1.0.0)
> این فایل روی **ویندوز واقعی** در GitHub Actions اجرا و تست شده است (بالا آمدن سرور، سرو صفحهٔ فارسی، ثبت/جست‌وجو، ساخت فایل SQLite).

### حالت اول — فایل آمادهٔ exe (توصیه‌شده)
1. از صفحهٔ **Releases** همین مخزن، فایل `GhazaPors-win-x64.zip` را دانلود کنید:
   <https://github.com/parsapeyman10/ghaza_pors/releases/tag/v1.0.0>
2. آن را در یک پوشه باز کنید (مثلاً `D:\dahili\`). **روی فلش یا Desktop هم می‌شود** — چیزی در ویندوز نصب نمی‌شود.
3. روی `start.bat` (یا `GhazaPors.exe`) دابل‌کلیک کنید.
4. مرورگر خودکار آدرس `http://127.0.0.1:8787` را باز می‌کند. پنجرهٔ سیاه را نبندید؛ تا باز است برنامه کار می‌کند.

> اگر `GhazaPors.exe` را نساخته‌اید، از **پوشهٔ پروژه + Node.js** هم می‌شود اجرا کرد:
> `npm install` سپس `npm start` (یا همان `start.bat` که خودش Node را امتحان می‌کند).

### ساخت خود exe روی کامپیوتر خودتان (۲ دقیقه)
```bash
npm install
npm run package:win        # => dist\GhazaPors.exe
node scripts/make-dist.js  # => dist\GhazaPors-win-x64.zip (پک کامل پرتابل)
```
این ساخت فقط به Node.js نیاز دارد؛ Visual Studio یا هیچ کامپایلری لازم نیست.
(در GitHub Actions هم خودکار ساخته می‌شود — بخش ۶.)

## ۲) کار با برنامه

**ثبـت:** دو ورودی اصلی طبق خواسته شماست —
`نام و نام خانوادگی` و `شمارهٔ تلفن داخلی` (یک ورودی اختیاری «توضیحات» هم هست).
با دکمهٔ «ذخیره در دیتابیس» بلافاصله در فایل SQLite نوشته می‌شود.

**جست‌وجو با پیشنهاد:** در کادر جست‌وجو که تایپ کنید، لیست اسامی ذخیره‌شده **به‌همراه شمارهٔ داخلی**
زیر کادر ظاهر می‌شود. با `↑` `↓` جابه‌جا و با `Enter` انتخاب کنید؛ کارت «یافت شد» شماره را بزرگ نشان می‌دهد
و دکمهٔ **کپی شماره**، **ویرایش** و **حذف** دارد.

جست‌وجو هوشمند است:
- ارقام فارسی و لاتین یکی‌اند: `۲۳۴۵` == `2345`
- نیم‌فاصله و تفاوت حروف عربی/فارسی فرقی نمی‌کند: `علي` == `علی`، `زه‌را` == `زهرا`
- هم روی اسم، هم روی شمارهٔ داخلی، هم روی توضیحات جست‌وجو می‌کند؛ چند کلمه = هر چند کلمه باید پیدا شود.

**فهرست:** همهٔ ثبت‌شده‌ها با فیلتر، ترتیب (نام / داخلی / تازه‌ترین)، ویرایش و حذف (با تأیید).
فیلد ردیف را **دوبار کلیک** کنید تا شمارهٔ داخلی کپی شود.

**میان‌برها:** `Ctrl+K` یا `/` رفتن به کادر جست‌وجو · `Enter` انتخاب پیشنهاد · `Esc` بستن لیست پیشنهاد.

**ابزارها (منوی بالا):** خروجی اکسل CSV · دانلود فایل دیتابیس (بکاپ) · بازیابی از بکاپ · ورود دسته‌جمعی (Paste از اکسل) · نمایش آدرس شبکه.

## ۳) استفادهٔ مشترک در شبکهٔ داخلی

روی **یک** سیستم (همان که فایل دیتابیس آنجاست) برنامه را باز نگه دارید؛
بقیهٔ همکاران در مرورگر آدرس زیر را می‌زنند:

```
http://<IP-of-host>:8787
```

آدرس‌های درست را خودِ برنامه موقع بالا آمدن چاپ می‌کند (و در دکمهٔ «ابزارها ← نمایش آدرس شبکه» هست).

- اگر همکار نتوانست وصل شود: در سیستم میزبان `firewall-allow.bat` را یک‌بار اجرا کنید (قاعدهٔ فایروال برای پورت ۸۷۸۷ می‌سازد).
- همه روی **یک دیتابیس** کار می‌کنند؛ وقتی کسی رکوردی ثبت کند، فهرست بقیه تا چند ثانیه خودکار تازه می‌شود.
- برنامه خودش نگهبان است: اگر نمونهٔ دیگری روی همان فایل دیتابیس باز باشد، دومی اجرا نمی‌شود
  (پیام «قفل است» می‌دهد) تا اطلاعات روی هم نوشته نشود.

## ۴) دیتابیس

فایل `data/dahili.sqlite` یک دیتابیس استاندارد SQLite است:

| کار | روش |
|---|---|
| بکاپ | کپی کردن همان فایل، یا «ابزارها ← دانلود فایل دیتابیس» |
| بازگردانی | «ابزارها ← بازیابی از فایل دیتابیس» |
| بازکردن با ابزار دیگر | DB Browser for SQLite / Excel با افزونه / `sqlite3` |
| انتقال به سیستم دیگر | کل پوشهٔ برنامه را کپی کنید (یا فقط فایل sqlite را به سیستم میزبان منتقل کنید) |
| دیتابیس روی شبکه | `config.json → "database": { "file": "\\\\SERVER\\share\\dahili.sqlite" }` |

ساختار جدول:

```sql
CREATE TABLE contacts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  full_name TEXT NOT NULL,   -- همان چیزی که کاربر تایپ کرده
  name_norm TEXT NOT NULL,   -- نرمال‌شده برای جست‌وجو
  extension TEXT NOT NULL,   -- شمارهٔ تلفن داخلی
  ext_norm TEXT NOT NULL,
  ext_compact TEXT NOT NULL UNIQUE, -- جلوگیری از شمارهٔ تکراری
  note TEXT,
  created_at TEXT, updated_at TEXT
);
```

## ۵) تنظیمات — `config.json`

کنار برنامه، یک فایل متنی ساده است؛ بعد از هر تغییر، برنامه را یک‌بار ببندید و باز کنید.

```json
{
  "app": { "title": "دفترچهٔ شماره‌های داخلی", "subtitle": "…" },
  "server": { "host": "0.0.0.0", "port": 8787, "openBrowser": true },
  "database": { "file": "data/dahili.sqlite" },
  "security": { "editPin": "" },
  "ui": { "listLimit": 500, "suggestLimit": 12 }
}
```

- `"port": 8787` — اگر پورت مشغول بود عدد دیگری بگذارید (یا با `-port 8899` اجرا کنید).
- `"host": "0.0.0.0"` — لازم برای دسترسی بقیهٔ سیستم‌ها. برای فقط‌همین‌سیستم `"127.0.0.1"`.
- `"security": { "editPin": "1234" }` — با گذاشتن رمز، برای **ثبت/ویرایش/حذف** رمز لازم است
  (دیدن و جست‌وجو برای همه آزاد است). برای حذف رمز دوباره `""` بگذارید.
- `"app": { "title": "…" }` — عنوان بالای صفحه را به نام سازمان خودتان تغییر دهید.

گزینه‌های خط فرمان: `--port` `--host` `--data` (`--db`) `--config` `--no-browser` `--force` `--help`
متغیرهای محیطی: `GHADA_PORT` `GHADA_HOST` `GHADA_DB` `GHADA_PIN` `GHADA_CONFIG` `GHADA_NO_BROWSER`

## ۶) ساخت خودکار exe با GitHub Actions (بدون هیچ نرم‌افزاری روی کامپیوتر شما)

1. این مخزن را در GitHub دارید؛ فقط کافی است یک تگ بسازید و push کنید:
   ```bash
   git tag v1.0.0 && git push origin v1.0.0
   ```
2. از **Actions** همین مخزن، workflow «ساخت فایل پرتابل (exe)» اجرا می‌شود (حدود ۳ دقیقه).
3. در پایان، سه فایل ZIP روی **Releases** می‌آید: `GhazaPors-win-x64.zip`، `…linux-x64.zip`، `…macos-x64.zip`.
   (در همین workflow، فایل اجرایی روی یک **سیستم ویندوزی واقعی** هم اجرا و تست می‌شود:
   بالا آمدن، سرو شدن صفحهٔ فارسی، ثبت رکورد، جست‌وجو با رقم فارسی/لاتین و ساخت فایل SQLite.)
4. همین. فایل را دانلود و باز کنید.

اگر تگ نزدید، از تب **Actions** دکمهٔ *Run workflow* را بزنید تا ZIPها را به‌عنوان Artifact بگیرد.

## ۷) ساختار پروژه

```
server/
  main.js        سرور HTTP + مسیرهای API (فقط ماژول‌های داخلی Node)
  db.js          دیتابیس SQLite، جست‌وجو، قفل فایل، ذخیرهٔ اتمیک
  config.js      پیکربندی (config.json / خط فرمان / متغیر محیطی)
  text.js        نرمال‌سازی فارسی + ترتیب الفبای فارسی + هایلایت نتیجه
  vendor/        موتور SQLite (wasm) که داخل exe بسته می‌شود
public/
  index.html · app.js · styles.css     رابط کاربری (آفلاین، بدون CDN)
scripts/
  make-vendor.js  به‌روزرسانی موتور SQLite
  seed.js         داده نمونه برای تست
  smoke.js        ۴۰ تست لایهٔ دیتابیس/API
  ui-smoke.js     ۲۴ تست رابط کاربری با jsdom (تایپ، اینتر، فرم، ویرایش، حذف…)
  exe-smoke.js    تست خودِ فایل exe (در CI روی ویندوز واقعی هم اجرا می‌شود)
  make-dist.js    ساخت پک‌های ZIP پرتابل
```

توسعهٔ محلی:

```bash
npm install
npm run dev          # اجرا بدون بازکردن خودکار مرورگر
npm run seed         # ۱۲ رکورد نمونه برای تست (برنامه خالی بالا می‌آید)
npm run check        # ۴۰ تست API + ۲۴ تست رابط کاربری
npm run check:exe    # تست فایل اجرایی ساخته‌شده (بعد از package)
```

## ۸) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| ویندوز SmartScreen/آنتی‌ویروس جلوی exe را گرفت | روی *More info → Run anyway*؛ یا `start.bat` با Node.js اجرا کنید؛ یا آنتی‌ویروس را برای پوشهٔ برنامه استثنا کنید |
| «پورت مشغول است» | برنامه از قبل باز است (همان را استفاده کنید) یا در `config.json` پورت را عوض کنید |
| همکار وصل نمی‌شود | `firewall-allow.bat` را روی سیستم میزبان اجرا کنید؛ `ipconfig` را برای IP درست چک کنید؛ مطمئن شوید شبکه Private است |
| «قفل دیتابیس دست برنامهٔ دیگری است» | یک نمونه دیگر روی همان فایل باز است؛ آن را ببندید (در شرایط اضطرار `--force`) |
| رمز ویرایش فراموش شد | `config.json → "editPin": ""` بگذارید و برنامه را ری‌استارت کنید |
| فایل دیتابیس خراب شد | برنامه خودش فایل خراب را به کنار می‌گذارد و تازه می‌سازد؛ بکاپ آخر را از «بازیابی از فایل دیتابیس» برگردانید |

**نکتهٔ امنیتی:** ارتباط HTTP ساده است (بدون TLS) و رمز `editPin` به‌صورت متن در `config.json` می‌ماند؛
این برای شبکهٔ داخلی اداره کافی است، اما برای اینترنت مناسب نیست.
